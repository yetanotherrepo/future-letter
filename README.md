# Письмо в будущее · future-letter

Скилл для тёплого, личного письма самому себе на выбранную будущую дату. Агент проводит интервью по одному смысловому блоку, а затем собирает цельное письмо из ваших ответов, сохраняя детали и вашу интонацию.

Подходит для начала спринта, 12-недельного года или другого важного периода. По умолчанию разговор идёт на русском; можно выбрать другой язык.

## Установка

Для Codex со стандартным расположением пользовательских скиллов:

```sh
mkdir -p "${CODEX_HOME:-$HOME/.codex}/skills"
git clone https://github.com/yetanotherrepo/future-letter.git \
  "${CODEX_HOME:-$HOME/.codex}/skills/future-letter"
```

Если папка `future-letter` уже существует, сначала сравните её содержимое с новой версией и сохраните свои изменения. После установки начните новый чат.

В другом агенте с поддержкой skills поместите `SKILL.md` в папку `future-letter` в каталоге скиллов, который использует этот агент. `agents/openai.yaml` содержит дополнительные метаданные для Codex.

Можно также передать содержимое [SKILL.md](SKILL.md) в обычный чат как инструкцию для этой практики.

## Как начать

```text
Используй $future-letter. Помоги написать письмо себе к концу спринта.
Задавай вопросы по одному блоку.
```

Точную дату открытия можно указать сразу или уточнить в первом ответе. Отвечайте свободно, в том числе голосом. Можно пропускать вопросы, менять порядок и попросить собрать письмо раньше.

## Как проходит практика

1. Дата открытия и сегодняшний момент.
2. Состояние в начале периода.
3. Образ себя в конце.
4. Значимые изменения и их личный смысл.
5. Небольшие регулярные действия.
6. Трудности и возвращение к важному.
7. Близкие и отношение к себе.
8. Благодарность, опора и завершение.

После последнего ответа агент выдаёт полное письмо. Он не добавляет выдуманные цели, чувства или достижения и не требует оптимизма или выполнения всего плана.

## Отправка в будущее

В конце, после готового письма, скилл предлагает воспользоваться [future-mail.org](https://future-mail.org/): перенести туда текст и выбрать дату доставки. Это необязательный шаг; подсказка находится вне текста письма.

Автоматической отправки и интеграции с сервисом нет. Скилл не передаёт письмо внешнему сервису, не публикует его и не создаёт напоминания без отдельного запроса. Доставка через сервис в рамках этого проекта не проверялась.
