# Архитектура future-letter

## Scope and status
Декларативный скилл для личного письма себе в будущее. Обновлено 2026-10-27, Europe/Lisbon. Финальная подсказка future-mail.org и документация реализованы; состояние публикации отражено в `PROGRESS.MD`.

## Current architecture
- `SKILL.md`: назначение, условия вызова, восемь блоков интервью, сборка письма и границы практики.
- `agents/openai.yaml`: название, краткое описание и пример запроса для интерфейса Codex.
- `README.md`: описание и установка публичного пакета.
- `AGENTS.md`: правила сопровождения; `PROGRESS.MD`: состояние работ и результаты проверок.
- Исполняемого кода, сервера, базы данных и зависимостей времени выполнения нет.

## Interfaces and data
Пользователь отвечает в текущем чате; агент собирает письмо из этих ответов. Скилл сам не хранит ответы и не передаёт их внешним сервисам. future-mail.org — необязательная ссылка после письма, без API-интеграции. GitHub служит для распространения инструкций.

## Runtime and constraints
Исполнение инструкций обеспечивает агент с поддержкой skills либо чат с переданным текстом `SKILL.md`. Русский — язык по умолчанию; пользователь может выбрать другой. Даты, имена и содержание берутся из текущего разговора. Доставка и настройки внешнего сервиса не проверены этой задачей.

## Architectural decisions
- **ADR-001 — 2026-10-27, accepted:** сохранить скилл декларативным и самостоятельным. Для интервью и сборки письма достаточно инструкций; скрипты не требуются. Другие реализации не рассматривались.
- **ADR-002 — 2026-10-27, accepted:** предлагать future-mail.org после полного письма, отдельно от его текста. Это прямое требование пользователя; отправка остаётся отдельным действием. Автоматическая интеграция не входит в задачу.
- **ADR-003 — 2026-10-27, accepted:** публиковать только инструкции, метаданные и документацию в отдельном публичном репозитории. Личные ответы и служебные артефакты окружения не входят в пакет.
